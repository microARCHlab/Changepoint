######### ChangePoint #########
Reference-free authentication method that evaluates ancient dna degradation pattern based on the proportion of likelihood at which the sample fits in the no damage model versus expected damage of A --> T replacement.
The original conception of the program is done by Laura's previous colleague Yichen Liu, and the development of the model was done in collaboration with Adam Rohrlach. The most recent workflow and changepoint visualization script was written by Abby Gancz, and the current status of the Changepoint publication falls on Christine Ta with benchmarking this bioinformatics tool with other commonly used authentication program in paleomicrobiome/paleogenomics. 

# The folder contains three scripts: The first is subsampling of 100k sequences from the sample fastq files (denoted by 01_Changepoint_100k_subsample.sh), the second is the actual changepoint assessment to get resulting proportion assessment (denoted by 02_Changepoint.sh), and the last is a visualization R script to create bar plots of 3' and 5' end proportion (03_Changepoint_Visualization.R).
